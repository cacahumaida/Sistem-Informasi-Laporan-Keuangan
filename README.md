# 💰 Financial Report Information System (Financial Tracker App)

Aplikasi manajemen dan pencatatan laporan keuangan pribadi berbasis web/mobile yang dirancang untuk memudahkan pengguna dalam memantau pemasukan, pengeluaran, serta pengelolaan kategori keuangan secara terstruktur, transparan, dan mudah diakses.

---

## ✨ Fitur Utama (Key Features)
* **Autentikasi Pengguna:** Sistem pendaftaran akun (*Sign Up*) dan login yang aman bagi pengguna.
* **Dashboard & Kalender Finansial:** Menampilkan ringkasan total pemasukan dan pengeluaran secara visual serta navigasi kalender interaktif untuk memantau transaksi harian.
* **Form Input Data Keuangan:** Formulir pencatatan transaksi yang fleksibel untuk menginput tanggal, kategori (seperti Gaji, Uang Saku, Transportasi, Skincare, dll.), nominal, serta keterangan tambahan.
* **Laporan Riwayat Keuangan (*History Laporan*):** Memfilter dan memantau riwayat transaksi berdasarkan rentang waktu (Bulan Ini, Bulan Lalu, hingga 3 Bulan terakhir).
* **Manajemen Kategori (*Kategori*):** Mengelola kategori pemasukan dan pengeluaran secara kustom (tambah, edit, dan hapus kategori).
